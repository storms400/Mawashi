# مواشي | Mawashi

تطبيق أندرويد مستقل لإدارة القطيع والرعاية البيطرية والأعلاف والمخزون والعمليات المالية، بواجهة عربية واتجاه RTL.

## الأقسام
- القطيع: ملفات الحيوانات، الأرقام التسلسلية، QR، الوزن والحالة الإنتاجية، الأرشفة والاستعادة.
- الرعاية والأدوية والتطعيمات: معلومات إرشادية، دفعات المخزون، تواريخ الصلاحية، التذكيرات، متابعة الوزن وحالة الجسم.
- الأعلاف: مخزون المكونات، تقدير الاحتياجات الغذائية حسب الوزن والحالة الإنتاجية وجودة المرعى، ومتابعة الاستهلاك.
- المالية: المشتريات والمبيعات والمصاريف والإيرادات والفواتير والتقارير.

## التقنية
- Kotlin و Jetpack Compose و Material 3
- Android SDK 35 و JDK 17
- حزمة التطوير المستقلة v32: `dz.mawashi.app.independent.v32`
- بيانات محلية عبر SharedPreferences/JSON في هذا الإصدار؛ لا يتضمن هذا الفرع بعد مزامنة سحابية أو حسابات مستخدمين أو فوترة Google Play.

## البناء والاختبار
```bash
gradle --no-daemon :app:testDebugUnitTest
gradle --no-daemon :app:assembleDebug
```

تحقق CI من رقم الحزمة والإصدار ووجود أيقونة التطبيق، ويرفع APK تجريبياً كأثر بناء.
